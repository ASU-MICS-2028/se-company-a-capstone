# Deliverables

The documentation package the brief asks for. Each area has an owner issue. Create the folder when you first add to it.

| Folder | What goes in it | Issue |
|---|---|---|
| `docs/proposal/` | Concept note and the 2-4 page proposal | [#1](../../../issues/1), [#2](../../../issues/2) |
| `docs/requirements/` | Functional and non-functional requirements, user stories, acceptance criteria, traceability | [#5](../../../issues/5) |
| `docs/ux/` | Personas, workflows, low- and high-fidelity wireframes, usability notes | [#6](../../../issues/6) |
| `docs/architecture/` | C4 diagrams, data flows, schema, `openapi.yaml`, deployment assumptions | [#7](../../../issues/7) |
| `docs/quality/` | Test plan, risk register, availability and reliability calculations | [#11](../../../issues/11), [#12](../../../issues/12) |
| `docs/scrum/` | Sprint backlogs, burndown charts, retrospectives, board exports | [#3](../../../issues/3), [#15](../../../issues/15) |
| `docs/brand/` | Nyansapo Systems logo files and usage | [#4](../../../issues/4) |
| `docs/presentation/` | ASERC slides and demo script | [#16](../../../issues/16) |
| `docs/ethics.md` | Ethics, social impact, AI use declaration | [#14](../../../issues/14) |
| `paper/` (repo root) | ACM paper source | [#13](../../../issues/13) |

Decisions behind these documents go in [`decisions/`](../decisions/index.md), not in here.
