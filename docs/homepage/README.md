# Twɛn homepage draft

`index.html` is a static draft of the patient-facing homepage. Open it in a browser; it needs no build step. The logos are inlined from `docs/brand/`.

Features we have not built yet are disabled and tagged "Coming soon" with the sprint they land in. Example screens use a made-up clinic.

This is a reference, not the app. When #10 sets up the React + TypeScript + Vite frontend ([decision](../../decisions/2026-11-16-frontend-typescript-vite.md)), port this page into it as the first route and turn each "Coming soon" into a working feature as its sprint lands.
