# Set up the Scrum board, roles and sprint cadence

Issue: [#3](https://github.com/ASU-MICS-2028/se-company-a-capstone/issues/3)

## Goal

Run the project as Scrum from day one, so the evidence for Scrum Project Management (10%) builds up without extra work.

## Done when

- [ ] GitHub Project board with Backlog / Sprint / In progress / Review / Done, holding every issue
- [ ] Roles (Product Owner, Scrum Master, Developers) recorded in `decisions/`
- [ ] Sprint length, planning, stand-up and retro times agreed and written down
- [ ] Sprint 1 backlog chosen

## Inputs and outputs

- **Uses:** This issue list
- **Produces:** Board link in README; `decisions/<date>-scrum-roles-and-cadence.md`

## Steps

1. Create the board (needs `gh auth refresh -s project`, or use the web UI) and add all issues
2. Agree roles and cadence, then write the decision
3. Plan Sprint 1

## Out of scope

- Burndown and retro records (#15)
