# Write the full project proposal (2-4 pages)

Issue: [#2](https://github.com/ASU-MICS-2028/se-company-a-capstone/issues/2)

## Goal

Submit the Milestone 1 proposal. Implementation can't start until it is approved. Worth 10% of the project grade in the brief.

## Done when

- [ ] Every section the brief lists is present: title, problem and motivation, stakeholders and personas, system description, use cases, target users and UX, architecture and programming model, data (sources, flows, security), 6-week scope, ethical/legal/social
- [ ] 2-4 pages, exported as PDF, submitted
- [ ] Instructor approval recorded as a comment

## Inputs and outputs

- **Uses:** #1 decision; knowledge notes on the proposal contents
- **Produces:** `docs/proposal/proposal.md` and the PDF

## Steps

1. Split the sections across people. Each section can be written independently from the #1 decision
2. One editor merges them and cuts to 4 pages
3. Submit, and log the change in `changes/`

## Out of scope

- Final diagrams (rough sketches are enough here)
