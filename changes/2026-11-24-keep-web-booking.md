# Keep web booking in the scope cut

## What changed

The proposed scope-cut decision now keeps joining the queue from a web page as a **Must**. It is one small patient page on the same API and the same queue. WhatsApp stays a Won't.

## Why

The team decided on 24 Nov that smartphone users and companions should be able to join without dialling. The decision is still proposed and not yet approved by the Product Owner, so it is updated in place rather than superseded.
