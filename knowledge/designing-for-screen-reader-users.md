# Designing for screen-reader users

A **screen reader** is software that reads the screen aloud for blind or low-vision users. The lecturer's feedback on a cafeteria design for a blind student:

- **Alt text is essential.** Every image needs alternative text, a written description the screen reader can speak. It must be shown in the design, not just implied.
- **State the screen-reader flow explicitly** in the user journey (each screen announces its name, the main button stays in the same place, order called by number, not name).
- **Be explicit about choices.** Saying "we are not using option A" does not tell the reader you are using option B. Say what you use.
- **State the user's condition precisely** (totally blind? since what age?).

Ideas he liked from industry:
- A "call the counter" button for when the user is stuck.
- Staff headsets, as in fast-food chains, so servers can help a disabled customer without leaving the counter.
- Order screens visible to both customer and server, replacing paper tickets; this is more sustainable and reduces mistakes.
