# Build the software before the hardware

Reviewing the other company's auto-care proposal, which wanted live car data from an OBD-II Bluetooth dongle, the lecturer advised building the main software first and adding hardware later. Hardware brings delivery delays, setup problems for users and new failure modes. A working core is worth more than a half-connected device.

## Use it in the capstone

The same applies to Twɛn's optional extras (a ticket printer, a waiting-room display). The core is the queue, the SMS and the board. Extras come only after the 10 December core demo works.
