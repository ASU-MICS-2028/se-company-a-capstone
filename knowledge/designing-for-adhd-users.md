# Designing for ADHD users

From the lecturer's feedback on a cafeteria app built for a student with ADHD (attention deficit hyperactivity disorder). Features he praised:
- **Favourites** on the home screen; he asked for an **order again** button on them.
- **Clear status labels** (preparing, ready for collection, collected) and text, not colour alone.
- **One clear path**, a few items per screen to limit **cognitive load** (the mental effort needed to use something).
- **Interruption recovery**: return to where you left off.

His recommendations:
- Give a **progress map**: "you are seven steps from your food" (three via favourites), in a header that stays on every page, with done steps and the next step highlighted. Make the countdown engaging, for example a box with an image.
- **Allergens**: list all allergens for every food, but highlight only the ones in the user's profile, so the screen isn't full of warnings.
- Don't call a feature "**smart**" unless it is intelligent. A profile-based allergen filter is "customisable" or "dynamic".

## Use it in the capstone

Since our system must be "intelligent", only label features smart or AI when they really use AI. Use the progress map and interruption recovery ideas in our prototype flows.
