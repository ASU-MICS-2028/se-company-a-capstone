# Personal CSS signature style

AI-generated websites tend to look the same. The lecturer's fix is to keep **your own custom CSS** (style sheet) and attach it to your prompts.

How he built his:

1. Collect links to a few pages whose design you really like (he used three).
2. Ask an AI to extract a **hybrid** style from them.
3. Adjust it by hand, then have the AI generate the final CSS.
4. Reuse it on every project as a signature look.

A company can do the same with its own colours and identity, and the generated UI will then stand out instead of looking generic.

## Use it in the capstone

Create a Nyansapo Systems CSS or design-token file (brand colours, type, spacing). Use it in the prototype and the slides, and attach it to UI-generation prompts so every screen matches.
