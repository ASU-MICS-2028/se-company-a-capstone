# Cognitive walkthrough

A **cognitive walkthrough** is an expert method in which evaluators step through a specific task *as a new user would*. At each step they ask:

1. Will the user know what to do here?
2. Will they see the control that does it?
3. Will they connect that control with their goal?
4. After acting, will they understand the feedback and know they are making progress?

Any "no" is logged as a problem at that step. It suits first-time use and learnability, so it fits users with low digital literacy or new to a service.

Harte et al. used walkthroughs alongside [heuristic evaluation](heuristic-evaluation.md) in Phase 2, with the use case document and Phase 1 requirements as the reference.

Difference from heuristic evaluation: heuristics check the *whole interface against rules*. A walkthrough checks *one task, step by step, through a novice's eyes*.

## Use it in the capstone

Walk our core task (for example, first sign-up through first result) with a teammate playing the persona. Record failures per step as UX evidence for documentation B2.
