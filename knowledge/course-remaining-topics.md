# Course remaining topics

At the start of Lecture 13 the lecturer recapped the course's arc: interface (UX) design, agile development, software architecture and programming models. Two topics remained:

1. **Software quality engineering**, which includes **maths**. Claiming high availability or reliability needs calculations: availability, reliability, and basic **dependability** attributes of a system.
2. **Applied data programming**: data pipelines, data models, analytics and APIs. For AI there is also **MCP** (Model Context Protocol, a standard way to connect AI models to tools and data), and the class will compare APIs and MCPs.

Data structures and algorithms got a session after the patterns series (Lecture 12).

## Use it in the capstone

The quality engineering deliverable (test plan plus availability and reliability calculations) comes from topic 1. Our data pipeline and API (or MCP) design for the intelligent component comes from topic 2.
