# Course artifacts go on GitHub and Canvas

Logistics the lecturer set out in the first lecture:

- The department has a GitHub organisation for the class. Each team (company) has a team and assigned repositories there; put all project artifacts in them. Final products may be forked into the department's repository.
- On Canvas, students join one of the team groups so that one submission counts for every member.
- Weekly updates were due on Sunday.
- Don't do the usual minimum: push for thorough analysis of users, classify them, and create personas.
- Read the textbook. Using an AI tool to summarise is fine if you truly understand, but his questions are comprehensive, so read alongside it.

## Use it in the capstone

Keep every capstone deliverable (requirements, UX, C4, Scrum records, test plan, paper) in the team repo, and submit once per team on Canvas.
