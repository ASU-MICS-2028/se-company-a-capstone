# Capstone rubric criteria

Bands: **Exemplary 90–100%**, **Proficient 70–89%**, **Needs improvement 50–69%**, **Poor <50%**. The sheet is headed "HealthPod and SmartVest – ASERC Ready!" (probably example projects).

| Criterion | Wt | Exemplary looks like | Poor looks like |
|---|---|---|---|
| **A. Software prototype** | **25** | | |
| Functionality and features | 10 | Fully functional, innovative features | Not functional |
| Intelligent / data-driven components | 5 | Effective use of AI or data analytics | None |
| Integration and performance | 5 | Seamless, reliable performance | Unreliable |
| Code quality and repository | 5 | Clean, well-structured code with Git best practices | Poor structure |
| **B. Documentation package** | **20** | | |
| Requirements and UX design | 5 | Clear, detailed, user-centred | Missing |
| Architecture and design | 5 | Well-designed architecture diagrams | None |
| Testing and quality | 5 | Comprehensive testing and results | No testing |
| Research paper (ACM) | 5 | Insightful, well-referenced paper | Poor paper |
| **C. Scrum record** | **10** | | |
| Planning and tracking | 5 | Complete, accurate Scrum artefacts | Missing |
| Team collaboration | 5 | Effective use of Trello, Jira, etc. | None |
| **D. Technical architecture and design** | **15** | | |
| System design | 8 | Scalable, secure, well-architected | Flawed design |
| Innovative use of technologies | 7 | Creative and relevant tech stack | Inappropriate tech |
| **E. Presentation and communication** | **15** | | |
| Clarity and organisation | 7 | Engaging, professional | Confusing |
| Visuals and delivery | 8 | Excellent visuals and delivery | Poor delivery |
| **F. Ethical, social and impact** | **10** | | |
| Ethics and inclusion | 5 | Deep reflection on ethics and inclusion | None |
| Real-world impact | 5 | Clear societal and African relevance | No impact |

## Use it in the capstone

Assign one owner per row. Before each milestone, self-score every row against the Exemplary wording. Note that "team collaboration" is judged from tool evidence (Trello, Jira, GitHub Projects), so keep the board current.
