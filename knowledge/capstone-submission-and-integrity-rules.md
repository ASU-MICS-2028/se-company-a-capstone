# Capstone submission and integrity rules

**Integrity (brief, section 7)**
- Follow the Ashesi Honour Code.
- AI tools may be used responsibly, but **must be documented in the paper** as an AI Use Declaration.
- All data must meet ethical standards and privacy guidelines.
- Collaboration stays inside the Company. Any cross-group collaboration must be declared.

**Tension with the syllabus.** The syllabus AI policy bans AI for assignments, projects and quizzes "unless stated by the faculty". The brief is that statement for this project, so AI is allowed here if it is declared.

**Submission (brief, section 8)** via GitHub Classroom + Canvas:
- Git repo link with the documentation package
- Compiled software artefacts
- PDF of the ACM paper
- Presentation slides

**Late penalty:** 10% of the final project grade per day, unless formally excused. (The syllabus's general rule for labs is 10% per 12 hours.)

## Use it in the capstone

Keep a running AI-use log (tool, purpose, what we changed) in the repo, so the declaration is easy to write. Do not put personal data from real users in the public repo.
